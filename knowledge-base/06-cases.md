# 06. 케이스별 처리 (Cases)

## 외국인
- **가능한 비자**: 모두 가능 (F-2, F-4, F-5, E-7, D-2 등) / 불법체류자는 불가
- **게재 안내 프레임 (2026-07-23 컴플라이언스)**: 외국인 안내는 **"여권 지참 + 매장 방문"**으로만 쓴다.
  비대면 셀프개통은 **한국 간편인증(PASS 등) 가능자만** 가능하다고 안내.
- **회선 한도**: 1회선
- ⚠️ 콘텐츠에 체류 신분증 명칭(외국인 등록 서류 등)을 쓰지 말 것 (게재 금지어).
  서류 상세가 필요한 손님은 1:1 채팅 상담으로 유도.

## 신용불량자
- **신용조회 없음** → 무조건 가능
- 타사 미납 있어도 OK
- ⚠️ 단, **앤텔레콤 자사 미납이 있는 경우 개통 불가**

## 미성년자
- **만 14세 이상**: 본인 명의 개통 가능 (보호자 동행 필수)
- **만 14세 미만**: 법정대리인을 통한 개통
- **회선 한도**: 선불·후불 각 1회선
- **필요 서류**:
  - 법정대리인 직접 내방: 법정대리인 신분증, 가족관계확인서(3개월 이내), 미성년자 신분증, 고객본인확인서
  - 대리인 내방: 인감증명서, 인감도장 날인 위임장, 대리인 신분증 추가

## 법인
- **선불폰**: 개통 불가
- **후불 알뜰폰**: 최대 4회선까지 가능
- **설립 6개월 미만 또는 유한회사**: 1회선만 가능

## 통신비 미납자
- **타 통신사 미납**: 개통 가능 (선불은 신용조회 X)
- **앤텔레콤 자사 미납**: 개통 불가
- ⚠️ **번호는 못 살린다 (2026-07-14 운영자 확정)**: 요금 미납·정지·직권해지 상태에서는
  **기존 번호 유지(번호이동)가 불가**하다. 선불 개통은 **새 번호**가 발급되는 것이고,
  살릴 수 있는 것은 **단말기(폰 기기)**뿐이다.
  → 콘텐츠에서 "기존 번호 그대로", "번호 살릴 수 있다", "번호 유지" 표현 절대 금지.
  올바른 표현: "폰(기기)은 그대로 쓰고, 번호는 새로 받아요"

## 정지·해지 상태
- **수신정지 폰**: 선불폰으로 즉시 해결 가능
- **발신정지 폰**: 선불폰으로 즉시 해결 가능
- **직권해지 폰**: 선불폰으로 개통 가능
- **30일 이내 앤텔레콤 해지 이력**: 셀프개통 불가, 매장 방문 필요

## 투폰·서브폰·세컨폰 희망자
- 투폰 개통 = 선불 유심으로 **새 번호를 하나 더** 만드는 것. 신용조회 없음, 5분 비대면.
- **정상 사용 중인 회선이 있는 경우에만** "지금 쓰는 번호는 그대로 두고, 두 번째 번호를 추가"라고
  말할 수 있다 (기존 회선은 해지되지 않으므로 사실).
- ⚠️ **미납·정지 상태인 사람에게는 이 표현 금지 (2026-07-21)**: 그 사람의 기존 번호는
  정지·소멸 대상이라 투폰 개통과 무관하게 **살릴 수 없다**. 미납자 대상 투폰 글에서는
  "기기(폰)는 그대로 쓰고, 번호는 새로 받는다"로만 서술 — "기존 번호 그대로/유지" 절대 금지.
- 미납자 케이스 규칙(위 '통신비 미납자' 항목)이 투폰 글에도 그대로 적용된다.

## 명의도용/대포폰 의심자
- 개통 **불가** (법적 보호)

## 회선 제한 총정리

| 대상 | 최대 회선 | 비대면 가능 |
|------|---------|-----------|
| 내국인 (신용 양호) | 3회선 | ✅ |
| 미성년자 | 선불·후불 각 1회선 | ❌ (매장 방문) |
| 외국인 (한국 간편인증 가능자) | 1회선 | ✅ |
| 외국인 (여권 지참) | 1회선 | ❌ (매장 방문) |
| 법인 | 후불 4회선 | ❌ (선불 불가) |
| 법인 (6개월 미만/유한회사) | 후불 1회선 | ❌ |
