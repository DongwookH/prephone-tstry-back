# 07. 글 작성 규칙 (Content Rules)

## 톤앤매너
- **친근한 존댓말** (~해요, ~끝나요, ~기억해 주세요)
- 짧은 문장 (12~18자 평균)
- 이모지 활용: 📌 ✅ 💬 📱 🔍 ⬅️ ⚠️ 🔑

## 반드시 반복 강조할 핵심 메시지 (3~5회)
1. **5분 비대면 셀프개통**
2. **신용조회 없음** (신용불량자도 OK)
3. **약정·위약금 없음** (일반 요금제)
4. **승인 대기 없음** (홈페이지 개통 시)
5. **앤텔레콤 안심개통 케어통신** (브랜드)

## 금지 표현 (절대 사용 X)
- "100% 보장", "100% 가능" — 과장 광고 금지
- "무조건 가능" — 케이스별 예외 있음
- "다른 업체는 안 됨" — 비방 금지
- 경쟁사 명칭 직접 비방
- 외부 링크 인용 (자제)

## 🚫 게재 금지어 (컴플라이언스 — 하나라도 쓰면 글 폐기, 2026-07-23 사업주 확정)
- **"외국인등록증"** — 외국인 안내는 "여권 지참 + 매장 방문" 프레임으로만
- **"더지통신" / "앤스마트"** — 내부 상호·전산명, 절대 노출 금지
- **"다이소" / "스카이라이프"** — 유심 안내는 KT 바로유심·LG 모두의 원칩만
- **"24시간"** — 개통 시간: 신규 08:00~21:50, 번호이동 10:00~19:50(일·명절 당일 불가)
- **"공식" / "본사" / "직영"** — 우리는 "**인증판매점**". 자기 지칭·타사 지칭 모두 금지
- **"고객센터" / "개통센터"** — 상담 안내는 "**1:1 채팅 상담(카카오 채널)**"로
- 판매점 고지(disclaimer) 문구는 글에 넣지 않는다 (2026-07-23 사업주 결정). 판매점명 표기가 필요하면 "**앤텔레콤 안심개통 케어통신**"

## 권장 표현
- "안심개통"
- "비대면 셀프"
- "케어통신"
- "5분이면 끝"
- "꼭 기억해 주세요"

## 가격·숫자 표기
- 가격: `12,100원` / `33,000원` (콤마 포함)
- **단정 표기 가능한 확정 공식가는 6종뿐**: 12,100 / 33,000 / 39,600 / 45,900(K망 전용) / 46,400(L망 전용) / 85,900원 — 이외 숫자 단정 금지
- 시간: `5분`, `5~10분` (한국식)
- 전화: `010-2311-6543` 또는 `010 2311 6543`
- 상담 안내: **1:1 채팅 상담(카카오 채널)** — 전화번호·상담조직 명칭은 쓰지 않는다

- 모르는 정보는 "자세한 내용은 [홈페이지](https://ntelecomsafe.com) 또는 [1:1 채팅 상담](https://pf.kakao.com/_Sxmxixon/chat)에서 확인" 식으로 우회
