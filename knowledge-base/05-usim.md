# 05. 유심 호환 (USIM)

## 사용 가능한 유심 (정확)

| 유심 | 가격 | 구매처 |
|------|------|--------|
| **KT 바로유심** (K망) | 8,800원 | 이마트24, CU, GS25 편의점 |
| **LG U+ 모두의유심원칩** (L망) | 8,800원 | 이마트24, 스토리웨이, 배민 B마트, 지하철 자판기 |

## 사용 불가능한 유심
- 이외 타 알뜰폰 유심: **사용 불가**
- SKT 통합유심: 호환 X
- 기존 통신사 사용 유심: 호환 X

## 유심 구매처 (실제)
| 구매처 | 가능 여부 |
|--------|---------|
| GS25 | ✅ (KT 바로유심) |
| CU | ✅ (KT 바로유심) |
| 이마트24 | ✅ (양망 모두) |
| 스토리웨이 | ✅ (LG 모두의유심) |
| 지하철 자판기 | ✅ (LG 모두의유심) |
| 배민 B마트 | ✅ (LG 모두의유심) |
| 우체국 | ❌ |
| 온라인 | 앤텔레콤 멤버십 K망 배송 접수 / 배민 B마트 |

> ⚠️ 위 표에 없는 판매처(생활용품점·위성방송 유심 등)는 게재 금지어라 콘텐츠에서 언급 자체를 하지 않는다 — 안내는 KT 바로유심·LG 모두의 원칩(모두의유심)만.
